# macOS 邮件客户端 · 界面方向 02

> 历史探索快照，未获最终批准。设计、架构和技术选型均未定稿；下文保留当时讨论措辞，当前状态以根目录 README.md 为准。

状态：可交互的视觉原型，尚未接入 Mailspring。`ARCHITECTURE.md` 的技术选型保持不变。产品名 Mail 仅为占位。

**设计意图**

给同时管理工作、个人邮箱，而且会使用键盘和外部 agent 的 Mac 用户。打开后先判断什么值得看，再舒适地读完、回复或留到稍后。视觉上有秩序、有温度，长时间使用不疲劳。

领域词汇：信件、回信、联系人、邮筐、校样、附件、归档、订阅。色彩来自纸白、铝灰、石墨、蓝墨、纸袋褐、书页绿。签名特征是密度不同的收信与读信两区，以及带来源预览的“留给慢慢读”聚合：重要通信逐封处理，订阅留在同一列表中按组展开。

本版不使用邮件卡片墙、常驻 AI 助手栏或大面积品牌色。列表以字重和间隔组织；少量色彩标识选择与目的地；正文拥有最多空间。

**参考依据**

实际查看 Mimestream、Things、Shortwave 官方产品图，具体观察与链接在 `REFERENCES.md`。Mimestream 提供窗口与会话结构，Things 提供视觉节奏，Shortwave 提供聚合表达。不是三套界面的拼贴：统一采用系统字体、同一图标线宽、同一选择态。

| 极窄预览 | 620px 以下按列表 / 阅读两页切换，并提供返回按钮。只用于检视可适应性，不代表增加移动客户端范围。 |
| 导航 | 淡铝灰表面；选择使用淡蓝，其他入口以中性文字表达；置顶与稍后图标允许低饱和功能色。 |
| 邮件列表 | 约 74–80px 一行；发件人、主题、摘要三层；未读点在外侧；日期分组细线低于文字对比。选择态内缩且无阴影。 |
| 阅读区 | 单一纸白表面；24px 主题，完整桌面 14–15px 正文，行高 1.9；正文宽度受限，左右留白随窗口增长。紧凑预览最低 13px。 |
| 历史回复 | 一条短行展示上一封的发件人、摘要、时间；展开仍留在会话位置。 |

系统字体优先 `-apple-system` / SF，中文由 PingFang SC 回退。正式 macOS 使用系统窗口按钮、菜单、文件选择、通知与输入行为；原型里绘制的窗口按钮只是示意。图标原型为统一 24px viewBox、1.65px 线宽，正式落地沿用一套可授权资源。

**交互规则**

- 单击选信；J / K 切换；E 归档；H 稍后；P 置顶；R 回复；C 新建；⌘K 搜索与命令。输入框和中文输入过程中不抢占字母键。
- 归档、稍后操作即时更新本地视图并提供撤销。真实客户端还需要展示已定义的同步任务结果，原型只改变示例数据。
- 稍后菜单靠近触发按钮；显示具体返回时间。关闭时恢复焦点。
- 搜索和命令共用一个入口，支持键盘选择与 Escape。模态窗口内保持焦点。
- 订阅聚合显示数量及来源；展开后直接选信，保留列表上下文。
- 新建邮件使用聚焦的写信浮层，发件账号清楚可见；回复沿原会话原位展开。原型只保存示例草稿，不连接任何邮箱、不发送邮件。
- 界面选择立即响应；弹层淡入约 120ms。不为高频选信添加滑入动画，尊重减少动态效果设置。
- 外部 agent 连接和授权进入设置。主界面仍以邮件为中心；后续 AI 功能通过按需动作接入。
