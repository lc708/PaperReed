## 风格与取舍

冷白底色、石墨文字、无衬线字体、少量钴蓝。强调清楚的对齐关系和快速扫读。默认只显示收件箱；选择一封信后进入独立阅读视图，再通过返回按钮或 Escape 回到列表。

这与第三版的差异不仅是颜色：第三版同时显示列表和正文，强调书信感；第四版把扫信与读信分开，以一次模式切换换取更大的阅读空间。两种方案都保留精简操作，不恢复常驻功能侧栏、状态栏、头像和徽章。

## 核心规格

- 收件箱为横向列表：寄信人、主题、时间三列。不添加摘要与头像；未读通过字重区别。
- 钴蓝只用于主要写信动作、焦点和少量链接。选中行使用浅蓝底与细线，不为每封信增加卡片阴影。
- 顶部“全部 / 置顶 / 稍后”是直接进入的视图。“所有邮箱”菜单负责邮箱范围、归档与草稿；搜索与命令共用入口。
- 主标题 30px / 650，列表 12px，阅读标题 25px / 620，正文 14px / 1.85。全部使用系统无衬线字体。
- 阅读视图限制内容宽度，保留发件人、日期、正文、附件、回复；完整地址和历史往来按需展开。
- 列表中 J / K 仅移动选择，Enter 打开；阅读中 J / K 切换邮件，Escape 返回。E 归档、P 置顶、H 稍后、R 回复、C 写信、⌘K 搜索继续沿用。
- 窄窗口将三列邮件行变为发件人 / 主题两行，保持字号与明确的返回入口。
