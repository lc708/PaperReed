# Community conduct / 社区行为准则

欢迎不同背景和经验的参与者。讨论聚焦具体问题，尊重他人，允许不同意见。不得骚扰、侮辱、歧视、泄露他人隐私或持续发布无关内容。未经同意不要公开私人交流。

Be respectful and constructive. Critique ideas and behavior, not people. Harassment, discrimination, threats, doxxing and persistent disruption are not welcome. Respect privacy and do not publish private correspondence without consent.

本准则适用于本仓库的 Issue、PR 和其他项目交流。维护者可编辑或移除违规内容，锁定讨论，或限制反复违规者的参与；处置应与行为相称。通过 GitHub 的 Report content 功能报告违规，或联系仓库维护者；不要为了举报而公开受害者的私人信息。

Maintainers may remove harmful content, lock discussions or restrict participation, proportionate to the behavior. Use GitHub's Report content tools or contact the repository maintainer to report violations without exposing private information.
