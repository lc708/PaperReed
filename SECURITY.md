# Security / 安全报告

当前没有正式版本，也未接入真实邮箱。安全报告范围包括本仓库原型、开发脚本、CI 和后续产品实现；尚无受支持的发行版本。

请通过 GitHub 的 [Report a vulnerability](https://github.com/macopc/mail-desktop/security/advisories/new) 私下报告漏洞。说明受影响提交、复现步骤、影响和最小示例。不要在公开 Issue / PR 中提交真实邮件、令牌、密码或可利用的漏洞细节。若发现第三方项目的问题，请联系该项目维护者。

There are no released or supported product versions yet. Use [GitHub private vulnerability reporting](https://github.com/macopc/mail-desktop/security/advisories/new) for issues in this repository. Include the affected commit, reproduction steps, impact and a minimal example. Do not post credentials, real email or exploit details publicly. Upstream vulnerabilities should be reported to the relevant maintainers.

This is a community project; response times are not guaranteed.
